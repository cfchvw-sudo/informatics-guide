# Информатика для первокурсника

**Тема:** системы счисления.

**Цель:** кратко разобраться в системах счисления и научиться переводить числа между ними.

**Автор:** wood

## Файлы проекта

- `glossary.md` — основные термины.
- `examples.md` — примеры перевода чисел с решениями.
- `sources.md` — использованные источники.
- `questions.md` — вопросы для самопроверки.
- `.gitignore` — правила исключения временных файлов.
