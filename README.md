# Информатика для первокурсника

**Тема:** системы счисления.

**Цель:** кратко разобраться, что такое системы счисления, чем отличаются их основания и как переводить числа из одной системы в другую.

**Автор:** wood

## Файлы проекта

- `glossary.md` — основные термины.
- `examples.md` — примеры перевода чисел с решениями.
- `sources.md` — использованные источники.
- `questions.md` — вопросы для самопроверки.
- `.gitignore` — список файлов и папок, которые Git не должен отслеживать.

## Как читать справочник

Сначала прочитайте `glossary.md`, чтобы разобраться в терминах. Затем изучите `examples.md` и попробуйте самостоятельно решить похожие задания. В конце проверьте себя по вопросам из `questions.md`.

## Как пользоваться справочником

1. Прочитать определения в `glossary.md`.
2. Посмотреть решения в `examples.md`.
3. Ответить на вопросы в `questions.md` и сверить ответы.

## Самопроверка

Вопросы и ответы для проверки знаний находятся в [questions.md](questions.md).
